# Estimator
A web application that allows users to estimate the cost of a project based on the project's requirements. The application is built using the Epic Stack by Kent C. Dodds

Local development requires Node.js 24. Install dependencies with `npm ci` and
start the application with `npm run dev`. Pushes to `main` deploy to the
existing `estimator-staging` Fly app; work on `dev` does not deploy automatically.
